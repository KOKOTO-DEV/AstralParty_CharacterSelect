# Astral Party Character Select 1.2.0

適用於 Steam 國際版的 BepInEx 6 IL2CPP 外掛，提供標籤、排序、隨機選擇和條件推薦。

僅在沒有設定的首次協作選角時，為已擁有且協作等級達到6的角色加上預設標籤。小町、楓、梅加斯還需確認潛能激發。保留既有設定和手動編輯。

## 安裝與設定

使用 BepInEx 啟動一次遊戲，退出後將 ZIP 內的 BepInEx 資料夾合併到遊戲目錄。只保留一份外掛 DLL。退出遊戲後可編輯 BepInEx/config/astral-party.character-select.cfg。Language 支援 Auto、Korean、English、Japanese、SimplifiedChinese、TraditionalChinese。Auto 根據顯示文字辨識語言，包含韓語補丁。設定說明使用韓語，自訂名稱保留原文。

在角色詳情設定標籤並編輯 51 個預設組合，在地圖圖鑑編輯 10 個地圖預設。排序依次為預設、座位、定位、自訂、手動。CustomOrder 接受標籤鍵或顯示名稱，ManualOrder 接受角色 ID。無有效輸入的模式會跳過。標籤和隨機按鈕每輪優先嘗試未選候選，再嘗試已選候選。最終確認仍由遊戲按鈕完成。

## 條件推薦

- 候選必須有標籤、可選、未受當前地圖排除，且至少符合一個包含隊友的啟用組合，或位於地圖推薦清單。固定座位的組合還要求座位標籤相符。
- 與隊友相符的每個組合、位於地圖推薦清單、符合當前座位標籤各加 1 分。同一組合只計一次。優先未被隊友選中的候選，再依總分、符合組合數、地圖推薦順序、組合登記順序排序。
- 反覆點擊可按排名循環到第一位。隊友變更後，下次點擊才重新排名。
- 緊急推薦預設關閉。可在角色詳情的全域設定中開關，設定每個定位的目標人數（1–4 人），並選擇輸出、輔助、卡牌和坦克標籤。預設選擇輔助。在個別設定中可切換該角色的候選資格。倒數經過 5 秒時只檢查一次，選擇能最大程度減少定位缺口的可選角色。未使用條件選擇時保留手動選擇。
- RecommendationDiagnostics 預設為 false，設成 true 後會在點擊時記錄隊友和候選角色 ID。
