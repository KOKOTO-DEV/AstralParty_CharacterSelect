# Astral Party Character Select 1.2.0

适用于 Steam 国际版的 BepInEx 6 IL2CPP 插件，提供标签、排序、随机选择和条件推荐。

仅在没有配置的首次协作选角时，为已拥有且协作等级达到6的角色添加预设标签。小町、枫、梅加斯还需确认潜能激发。保留已有设置和手动编辑。

## 安装与设置

使用 BepInEx 启动一次游戏，退出后将 ZIP 内的 BepInEx 文件夹合并到游戏目录。只保留一份插件 DLL。退出游戏后可编辑 BepInEx/config/astral-party.character-select.cfg。Language 支持 Auto、Korean、English、Japanese、SimplifiedChinese、TraditionalChinese。Auto 根据显示文字识别语言，包括韩语补丁。配置说明使用韩语，自定义名称保留原文。

在角色详情中设置标签、编辑 51 个默认组合，在地图图鉴中编辑 10 个地图预设。排序依次为默认、座位、定位、自定义、手动。CustomOrder 接受标签键或显示名，ManualOrder 接受角色 ID。无有效输入的模式会跳过。标签和随机按钮每轮优先尝试未选候选，再尝试已选候选。最终确认仍由游戏按钮完成。

## 条件推荐

- 候选必须有标签、可选、未受当前地图排除，并至少符合一个包含队友的启用组合，或位于地图推荐列表。固定座位的组合还要求座位标签匹配。
- 与队友匹配的每个组合、位于地图推荐列表、匹配当前座位标签各加 1 分。同一组合只计一次。优先未被队友选中的候选，再依总分、匹配组合数、地图推荐顺序、组合登记顺序排序。
- 反复点击可按排名循环到第一位。队友变化后，下次点击才重新排行。
- 紧急推荐默认关闭。可在角色详情的全局设置中开关，设置每个定位的目标人数（1–4 人），并选择输出、辅助、卡牌和坦克标签。默认选择辅助。在个别设置中可切换该角色的候选资格。倒计时经过 5 秒时只检查一次，选择能最大程度减少定位缺口的可选角色。未使用条件选择时保留手动选择。
- RecommendationDiagnostics 默认为 false，设为 true 后会在点击时记录队友和候选角色 ID。
