# 조건 추천 판정과 점수

조건 추천은 매치의 팀원 선택, 내 자리, 해당 맵 설정을 사용한다. `조건 선택` 버튼은 추천 캐릭터 선택을 시도하고 게임의 최종 확인 버튼은 누르지 않는다.

## 후보 판정

- 태그가 하나 이상 붙고 현재 맵의 `Excluded`에 없는 캐릭터를 검사한다. 미보유·밴 캐릭터는 선택 대상에서 빠진다. 내가 이미 고른 캐릭터는 순환 후보에 남을 수 있다.
- 후보가 되려면 현재 팀원 한 명 이상과 연결되는 활성 조합이 있거나, 해당 맵의 `Preferred`에 등록되어 있거나, 내 자리 태그와 일치해야 한다.
- 조합 하나는 현재 팀원 여러 명이 동시에 해당돼도 후보당 한 번만 센다. 세 명 이상의 조합도 현재 팀에 다른 구성원 한 명만 있으면 계산한다. 자리 고정 조합은 후보에게 내 자리 태그가 있을 때만 점수에 넣는다.

## 추천 순서

팀원이 아직 고르지 않은 후보를 먼저 배치한다. 각 그룹 안에서는 **일치한 조합 수 → 맵 추천 목록 순서 → 내 자리 태그 일치 여부** 순으로 비교한다. 앞 단계가 같을 때 다음 기준으로 비교한다. 내 자리 태그가 일치하는 후보끼리는 P1·P2에서 서포터, P3·P4에서 딜러 태그를 우선한다. 모든 기준이 같으면 현재 캐릭터 목록 순서를 따른다.

### 예시

원림 중정에서 내 자리가 P3이고 팀원이 테루·자스민·펭인 경우, 아래와 같이 태그를 지정했다면 유메가 먼저다.

| 후보 | 맞는 조합 | 맵 추천 포함 | P3 태그 |
|---|---:|---|---|
| 유메 | 2 | 예 | 없음 |
| 낸시 루 | 1 | 예 | 있음 |

현재 팀과 맞는 조합이 더 많은 유메가 앞선다. 실제 후보는 보유 여부, 태그, 맵 설정, 조합 편집 결과에 따라 달라진다.

## 버튼을 다시 눌렀을 때

같은 팀 구성과 후보 목록에서는 `1/6 순위`부터 차례로 진행하고 마지막 다음에 첫 순위로 돌아간다. 이미 팀원이 고른 후보는 뒤쪽에서 시도하며, 실제 중복 선택 가능 여부는 게임이 결정한다. 팀원이 캐릭터를 바꾸면 다음 클릭에서 다시 순위를 계산한다. 일반 조건 추천은 버튼 클릭으로 실행한다.

## 긴급 추천

기본값은 OFF다. 캐릭터 상세정보에서 `전체 설정 → 긴급 추천`을 열어 사용 여부, 역할당 목표 인원(1~4명), 확인할 역할 태그를 선택한다. 초기 목표는 역할당 1명이고 서포터만 선택되어 있다. 딜러·서포터·카드특화·탱커 중 여러 태그를 선택할 수 있으며, 각 태그에 목표 인원을 따로 적용한다. 한 캐릭터에 태그가 여러 개 있으면 해당 역할마다 집계한다.

켜진 경우 남은 시간이 **5초를 지날 때 한 번** 확인한다. 다른 팀원이 한 명 이상 골랐고 역할 인원이 부족하면, 내가 바꿨을 때 전체 부족 인원을 가장 많이 줄이는 후보를 고른다. 개선 폭이 같은 후보 중에서는 무작위로 고른다. 개별 설정에서 긴급 추천 후보를 켜 둔 캐릭터만 선택한다. 기본 후보는 파루난·카이세이다. 후보는 선택 가능하고 현재 팀원이 고르지 않은 캐릭터여야 하며, 맵 제외도 적용된다. 조건 선택을 사용하지 않고 직접 고른 캐릭터가 있으면 유지한다.
