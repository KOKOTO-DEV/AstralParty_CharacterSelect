# Astral Party Character Select 1.3.0

Steam国際版向けのBepInEx 6 IL2CPPプラグインです。タグ、並び替え、ランダム選択、チーム推薦を追加します。

新規設定の初回協力キャラクター選択画面で、所持済みかつ協力レベル6と確認できたキャラに初期タグを一度だけ付けます。コマチ、フェン、メガスは潜在解放の確認も必要です。既存の設定や手動変更は維持します。

## 導入と設定

BepInExでゲームを一度起動し、終了してからZIP内のBepInExフォルダーをゲームフォルダーに統合します。プラグインのDLLは一つだけ残してください。設定ファイルは BepInEx/config/astral-party.character-select.cfg です。終了後に編集してください。Language は Auto、Korean、English、Japanese、SimplifiedChinese、TraditionalChinese に対応します。Auto は韓国語パッチを含む表示テキストから判定します。設定項目の説明は韓国語です。ユーザーが入力した名前はそのまま表示します。

キャラクター詳細でタグと初期組み合わせ51件、マップ図鑑でマップ設定10件を編集できます。並びは標準、席順、役割、カスタム、手動の順に切り替わります。CustomOrder はタグキーまたは表示名、ManualOrder はキャラクターIDを使います。入力が無効なモードはスキップします。タグとランダムのボタンは未選択の候補を一巡した後、選択済みの候補も試します。最終確定はゲームのボタンで行います。

## 条件選択

- タグ付きで選択可能なキャラクターのうち、味方と有効な組み合わせがあるか、マップ推薦リストに入っている候補を対象にします。マップ除外を適用し、席順固定の組み合わせは席タグの一致が必要です。
- 味方と合う組み合わせ1件、マップ推薦、現在の席タグに各1点を加算します。同一の組み合わせは一度だけ数えます。味方の未選択候補が優先され、各グループ内では合計点、組み合わせ数、マップ推薦順、組み合わせ登録順で並びます。
- 条件選択を押すたびに順位を進み、最後の次は1位です。味方が変更した場合は次のクリックで再計算します。味方の変更だけで自分の選択が自動的に変わることはありません。
- 緊急推薦は初期状態でOFFです。キャラクター詳細の全体設定から、使用の有無、役割ごとの目標人数（1～4人）、確認する役割タグを選べます。初期選択は支援です。個別設定でそのキャラクターを候補に追加できます。残り5秒を切る時点で一度だけ判定し、役割の不足を最も減らす選択可能なキャラクターを選びます。条件選択を使わず手動で選んだキャラクターは維持します。
- RecommendationDiagnostics を true にすると、条件選択を押した時の味方と候補のIDをログに記録します。初期値は false です。
